三种分发策略对比
workflow() 同步子编排
等待子工作流完整执行
返回结构化结果

用于：
· task-splitter
· qa-check
· review-diff
· ship-to-product
agent() 独立 Agent
启动单个 agent 执行
异步等待结果

用于：
· 需求分析
· 编译/测试门控
· 单 agent 模式编码
parallel() 并发屏障
全部启动后等全部完成
结果汇聚再继续

用于：
· Review 修复 HIGH 问题
· Ship 问题修复
编排层次
主编排器 dev-to-prod → 决定什么时候做什么
子工作流 task-splitter / qa-check / review-diff / ship-to-product → 决定怎么做
调度器 dependency-scheduler → 决定并发跑几个、谁先跑
Agent spring-boot-coder / test-coder / code-reviewer → 实际执行具体工作
